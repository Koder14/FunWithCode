# Rock-Paper-Scissors Game

## Overview
This project is a video game version of the classic Rock-Paper-Scissors game. It features a graphical user interface and sound effects to enhance the gaming experience.

## Project Structure
```
rock-paper-scissors-game
├── assets
│   ├── audio
│   └── images
├── src
│   ├── main.py
│   ├── game
│   │   ├── __init__.py
│   │   ├── logic.py
│   │   └── ui.py
│   └── utils
│       └── __init__.py
├── requirements.txt
└── README.md
```

## Installation
1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd rock-paper-scissors-game
   ```
3. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Dependencies

To run this project, you need to install the following dependencies:

- `pygame`: A library for creating games and multimedia applications.
- `numpy`: A library for numerical computations.

Install them using the following command:

```bash
pip install -r requirements.txt
```

## Usage
To start the game, run the following command:
```
python src/main.py
```

## Assets
- **Audio**: Sound effects and background music will be stored in the `assets/audio` directory.
- **Images**: Icons, backgrounds, and other visual assets will be stored in the `assets/images` directory.
